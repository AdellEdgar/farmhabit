# Libros: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Sección Libros con estanterías, búsqueda, ficha, citas, reto anual y estadísticas, sin tocar el juego.

**Architecture:** Tres colecciones sincronizables nuevas (migración 6). Lógica pura en `domain/books.ts` y `domain/book-search.ts`, escrituras en `services/books.ts`, interfaz en `features/books/`. `computeGame` no se toca.

**Tech Stack:** TypeScript, React 19, Tailwind 4, Vitest, SQLite, zod 4, Open Library.

**Spec:** `docs/superpowers/specs/2026-11-04-libros-design.md`

## Global Constraints

- Sin commits ni push salvo que el usuario lo pida. Cada tarea termina con `pnpm check` en verde.
- Interfaz, documentación y comentarios en español; identificadores en inglés. El núcleo no importa React, Tauri ni DOM.
- Migraciones congeladas: se añade la 6.
- Los libros no entran en `computeGame`.

## Review Focus

1. Fusión con un archivo de una versión anterior, sin las colecciones nuevas: no se pierde nada. → Task 1.
2. Respuesta rara o parcial de Open Library (sin autor, sin páginas, sin portada, JSON inesperado): no rompe. → Task 2.
3. Un `coverUrl` de otro dominio, venido de un archivo sincronizado: no se carga. → Task 2.
4. Libro sin total de páginas: el progreso funciona sin porcentaje y nunca pasa a Leídos solo. → Task 2.
5. Varias actualizaciones de página el mismo día: `from_page` no cambia y las páginas no se cuentan dos veces. → Task 2.

### Task 1: Datos

Migración 6, `TABLES`, esquemas, tipos, `COLLECTIONS` (`books`, `bookQuotes`, `readingLogs`), fixtures `makeBook`, `AppData` y `FIELDS`. Tests: subir de 5 a 6 conserva los hábitos; crear y leer conserva campos; borrar vacía `title`, `author`, `review`; fusionar un archivo sin las colecciones no pierde las locales; `SCHEMA_VERSION` es 6.

### Task 2: Dominio y servicio

- `domain/book-search.ts`: `normalizeIsbn(text): string | null`; `bookSearchUrl(query): string`; `parseBookSearch(json: unknown): BookCandidate[]` con `{title, author, pages, coverUrl, isbn}`, que prefiere el título y la portada de la edición; `isAllowedCover(url): boolean`.
- `domain/books.ts`: `BookShelf`, `booksOnShelf(books, shelf)`, `bookPercent(book): number | null`, `finishedIn(books, year): number`, `readingStats(books, logs, year, today): ReadingStats`, `readingGoalKey(year)`, `parseReadingGoal(value): number | null`.
- `services/books.ts`: `BookError`, `readingLogId(bookId, date)`, `createBook(db, input, today)`, `updateBook(db, id, patch)`, `setBookStatus(db, id, status, today)`, `setBookProgress(db, id, page, today)`, `deleteBook(db, id)`, `addBookQuote(db, bookId, text, page)`, `deleteBookQuote(db, id)`, `setReadingGoal(db, year, goal)`.

Tests en `test/books.test.ts`: todas las reglas del progreso de la spec, los puntos 2 a 5 de Review Focus, cascada de borrado, nota no válida y estadísticas de un caso conocido.

### Task 3: Interfaz

`features/books/`: `BooksView`, `BookCard`, `BookCover`, `RatingStars`, `AddBookDialog`, `BookSheet`, `GoalCard`, `StatsTab`, `ReadingNow`. `lib/book-search.ts` hace la petición con plugin-http (o `fetch` en el navegador). Sección `libros` en `navigation` y `App.tsx`, con `React.lazy`. `ReadingNow` en Hoy. CSP: `img-src` añade `https://covers.openlibrary.org`. Comprobar la barra inferior a 360 px.

### Task 4: Demo y documentación

`demo-data.ts`: clásicos de dominio público, sin portada, repartidos por estanterías, con citas y registros. `CLAUDE.md`, `README.md`, `CHANGELOG.md` y captura `libros.png`. Fase 13. `pnpm check` y `pnpm test:rust`. Revisión final independiente y una pasada de arreglos.
